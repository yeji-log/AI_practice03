01경험을 이용한 탐색

너비우선탐색이나 깊이우선탐색처럼 문제에 대한 사전 지식 없이 정해진 순서대로만 노드를 확장하는 방식을 맹목적 탐색(blind search)이라 부릅니다. 반면 경험을 이용한 탐색(informed search)은 문제 영역에 대해 미리 알고 있는 지식 — 즉 경험적 지식 — 을 활용해서, 목표에 더 가까워 보이는 노드를 먼저 살펴봅니다.

맹목적 탐색

목표 방향에 대한 정보 없이 정해진 순서로만 확장. 너비우선탐색, 깊이우선탐색.

경험을 이용한 탐색

"어느 쪽이 목표에 더 가까운가"를 어림잡아 판단에 활용. 휴리스틱 탐색, 최상우선탐색, A*.

02휴리스틱 함수 h(n)

이 어림짐작을 수치로 표현한 것이 휴리스틱 함수 h(n)입니다. 노드 n에서 목표까지 실제로 드는 비용은 아직 모르지만, 경험을 바탕으로 "대략 이 정도일 것"이라 추정한 값입니다.

h(n) = |Δrow| + |Δcol| 이 시뮬레이터는 격자 위에서 목표까지의 맨해튼 거리를 휴리스틱으로 사용합니다 — 벽은 무시하고 직선 칸 수만 세는 값입니다.

휴리스틱은 정답을 보장하지 않는 안내자일 뿐입니다. 벽 같은 실제 장애물을 모르기 때문에, 종종 틀린 방향을 그럴듯하다고 가리키기도 합니다 — 오른쪽 시뮬레이터에서 이 점을 직접 확인할 수 있습니다.

03최상우선탐색

최상우선탐색(Best-First Search)이란, 열린 목록(open list)에 대기 중인 노드들 가운데 평가함수 f(n) 값이 가장 좋은(최상의) 노드를 매번 골라 확장해 나가는 탐색 전략을 통틀어 일컫는 말입니다. 이 시뮬레이터가 구현한 것은 그중 가장 단순한 형태인 탐욕적 최상우선탐색(Greedy Best-First Search) — 오직 f(n) = h(n)만 보고, 지금 이 순간 목표에 가장 가까워 보이는 노드로 그리디하게 이동합니다.

1open ← [ 시작 노드 ]   (h값 계산)2while open이 비어있지 않다:3    n ← open에서 h(n)이 최소인 노드4    open에서 n 제거, closed에 n 추가5    if n = 목표 노드 → 경로 반환 후 종료6    for each 이웃 in n의 이웃:7        if 이웃이 벽 or closed or open에 있음 → 건너뜀8        이웃의 h 계산 후 open에 추가
장점

매번 가장 유망해 보이는 노드만 확장하므로, 목표 방향으로 빠르게 파고들어 방문 노드 수가 적고 속도가 빠릅니다.

단점

지금까지 온 실제 비용 g(n)을 전혀 고려하지 않아 최단 경로를 보장하지 못하고, 벽 같은 지역적 함정에 취약합니다.

한 걸음 더 — 여기에 지금까지 이동한 실제 비용 g(n)을 더해 f(n) = g(n) + h(n)으로 평가하면 A* 탐색이 됩니다. 최상우선탐색의 속도와, 실제 비용을 함께 고려하는 균형 감각을 동시에 얻으려는 대표적인 확장입니다.
